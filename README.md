# Kingdom Impact Technologies — Free Web App

This is a zero-cost starter web app. It works on phones and computers and sends client requests to your WhatsApp number.

## Publish for free
Upload `index.html` to a free static hosting service such as GitHub Pages or Cloudflare Pages. No Google Play developer fee is required.

## Important
The client form intentionally uses WhatsApp rather than a paid database/backend, so you can start receiving leads without monthly hosting costs.
